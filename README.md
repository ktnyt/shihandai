# shihandai

薙刀式かな入力の段階練習ツール。
ターミナルで動く。

「ある」「ない」「する」を構成する「あいなする」の5文字から練習を始める。
ノーミスで目標打鍵速度（既定 120kpm）に達するたびに、使えるかなが1文字増える。
覚えたはずのかなの正答率が下がったら、1レベル戻る。

かなは次の順で増えていく。

1. あ い な す る
2. ベースレイヤーの清音（頻度順）
3. ベースレイヤー由来の濁音
4. 基本の拗音
5. シフトレイヤーの清音
6. シフトレイヤー由来の濁音
7. 半濁音
8. 濁音・半濁音の拗音
9. 外来音

例文はローカルの LFM2.5（Ollama 経由）が、そのレベルで打てるかなだけを使って生成する。
生成が検証を通らないときは、内蔵の単語バンクから組み立てる。

## 必要なもの

- Go 1.25 以上
- Ollama と LFM2.5（なくても動く。その場合は単語バンクだけで練習する）

```sh
ollama pull hf.co/LiquidAI/LFM2.5-8B-A1B-GGUF:Q6_K
```

## 使い方

```sh
go run ./cmd/shihandai
```

画面に出た例文を薙刀式で打つ。
かなの下に運指のヒント（`か → F`、`が → F+J`、`の → Space+J`）が出る。
Esc で終了する。進捗は自動で保存され、次回は続きから始まる。

主なフラグ:

| フラグ | 既定値 | 意味 |
|---|---|---|
| `-model` | `hf.co/LiquidAI/LFM2.5-8B-A1B-GGUF:Q6_K` | Ollama のモデル名 |
| `-url` | `http://localhost:11434` | Ollama のURL |
| `-window` | `80ms` | 同時押しの判定ウィンドウ |
| `-kpm` | `120` | 昇格に必要な打鍵速度 |
| `-min-acc` | `0.85` | これを下回ると降格する直近正答率 |
| `-no-llm` | `false` | LLMを使わない |
| `-reset` | `false` | 進捗を消してやり直す |

## 同時押しの扱い

薙刀式は同時押しを多用するが、ターミナルはキーリリースを検出できない。
そこで判定ウィンドウ（既定 80ms）内に押されたキーを同時押しとみなし、
QMK実装と同じ最長一致の貪欲法でかなに確定する。
単打のかなはウィンドウ経過後に確定するため、表示にわずかな遅延がある。
判定がうまくいかないときは `-window` を調整するとよい。

かな定義は [eswai/qmk_firmware](https://github.com/eswai/qmk_firmware) の
naginata_v15（薙刀式 v15）に準拠する。
編集モードは対象外。
