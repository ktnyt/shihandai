# shihandai

薙刀式かな入力の段階練習ツール。
ターミナルで動く。

「ある」「ない」「する」を構成する「あいなする」の5文字から練習を始める。
単語が1つずつ表示され、表示された瞬間から打ち終わるまでの時間を計る。
ノーミスかつ制限時間内に打てたら成功と数える。
打ち終わってから次の単語が出るまでには短いインターバルがあり、
その間のキー入力は無視される（打ち終わりの巻き込み防止）。

レベルは「かなの数 × 単語の長さ」の512段階。
かな1文字ごとに、2文字の語 → 3文字 → 4文字 → 5文字の4段階を踏む。
上の段階では短い語も出る。最終レベルに達すると長さの制限がなくなり、
6文字以上の語も出るようになる。

レベルアップの条件は2つ。
直近100単語の成功率が95%を超えていること、そして
いちばん新しいかなを含む語を50回以上打っていること。
辞書にその語が少ないかなでは、この50回は自動的にゆるめられる。
レベルアップするといったん結果画面を挟み、増えたかなの打鍵や
解放された長さを確認してから Space で練習に戻る。

覚えたはずのかなの打ち間違いが増えたら、1レベル戻る。
降格の対象は打ち間違いだけで、時間超過は数えない。
覚えている最中のいちばん新しいかなも対象外。
基準はゆるめで、そのかなの直近12回のうち4回以上を打ち間違えたときに降格する。

制限時間は「反応の猶予（既定1秒）＋打鍵数×目標打鍵速度（既定 120kpm）ぶんの時間」。
たとえば「ある」（2打鍵）なら 1秒 + 1秒 = 2秒。

かなは次の順で増えていく。

1. あ い な す る
2. ベースレイヤーの清音（頻度順）
3. ベースレイヤー由来の濁音
4. 基本の拗音
5. シフトレイヤーの清音
6. シフトレイヤー由来の濁音
7. 半濁音
8. 濁音・半濁音の拗音
9. 外来音

単語は頻度順の辞書（mozc の OSS 辞書から抽出した約2.2万語）から、
そのレベルのかなだけで打てるものを選ぶ。
新しく覚えるかなと苦手なかなを含む単語が優先して出る。

## 使い方

```sh
go run ./cmd/shihandai
```

画面に出た単語を薙刀式で打つ。
かなの下に運指のヒント（`か → F`、`が → F+J`、`の → Space+J`）が出る。

Esc で一時停止する。単語が隠れて計測も止まり、
Space で同じ単語を最初から打ち直す（計測もやり直し）。
一時停止中にもう一度 Esc を押すと終了する。
進捗は自動で保存され、次回は続きから始まる。

主なフラグ:

| フラグ | 既定値 | 意味 |
|---|---|---|
| `-window` | `80ms` | 同時押しの判定ウィンドウ |
| `-kpm` | `120` | 目標打鍵速度（制限時間の計算に使う） |
| `-react` | `1s` | 単語の表示から打ち始めるまでの猶予 |
| `-words` | `100` | 成功率を測る直近の単語数 |
| `-rate` | `0.95` | これを上回ったらレベルアップする成功率 |
| `-new-words` | `50` | 昇格までに打つ、新出かなを含む語の最低数 |
| `-interval` | `500ms` | 単語と単語の間の入力を受け付けない時間 |
| `-min-acc` | `0.70` | これを下回ると降格する直近正答率 |
| `-reset` | `false` | 進捗を消してやり直す |

## 同時押しの扱い

薙刀式は同時押しを多用するが、ターミナルはキーリリースを検出できない。
そこで判定ウィンドウ（既定 80ms）内に押されたキーを同時押しとみなし、
QMK実装と同じ最長一致の貪欲法でかなに確定する。
単打のかなはウィンドウ経過後に確定するため、表示にわずかな遅延がある。
判定がうまくいかないときは `-window` を調整するとよい。

かな定義は [eswai/qmk_firmware](https://github.com/eswai/qmk_firmware) の
naginata_v15（薙刀式 v15）に準拠する。
編集モードは対象外。

## 辞書の再生成

単語リスト `internal/dict/words.txt` は
[mozc](https://github.com/google/mozc) の OSS 辞書
（`src/data/dictionary_oss/`、BSD-3-Clause）から生成した。
作り直すときは `dictionary0*.txt` と `id.def` を置いたディレクトリを指定して実行する。

```sh
go run ./tools/mkdict -dict-dir <辞書のディレクトリ> -out internal/dict/words.txt -n 20000
```

一般語の基本形だけを残し、読みをひらがなに直し、
薙刀式で打てる語をコスト（頻度）順に並べている。
